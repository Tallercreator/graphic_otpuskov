# График команды — прототип модуля «Отпуск»

Собранный прототип для модерируемого юзабилити-теста.

- **Живая версия:** https://tallercreator.github.io/graphic_otpuskov/
- Здесь лежит только продакшен-билд (`vite build`), без исходников UI-кита.
- Исходники и команда редеплоя — в основном репозитории кита,
  ветка `prototype/otpusk`, см. `PROTOTYPE-NOTES.md`.

## Подсказки для модератора

- `?scenario=<имя>` в URL или ⌘⇧S — переключение сценариев
  (small, big, maternity, peak, yearPeaks, emptyMonth, emptyGroup, noGroup, longNames).
